Bangalore Restaurant Analysis Dashboard
An interactive data dashboard exploring 50,000+ restaurants across Bangalore using Zomato data.
🔗 Live Demo: bangalore-food-dashboard-c4ga8mwxqep87fswt7sjm2.streamlit.app
Features

Filter restaurants by location across 92 areas in Bangalore
Top 15 locations by restaurant count
Top 10 cuisine types
Rating distribution across all restaurants
Cost vs rating analysis
Online ordering vs average rating comparison

Tech Stack

Python — data processing
Pandas — data cleaning and analysis
Plotly — interactive charts
Streamlit — dashboard and deployment

Dataset
Zomato Bangalore Restaurants dataset from Kaggle — 51,000+ restaurants with ratings, cuisines, costs, and location data.
Key Insights

BTM has the highest restaurant density in Bangalore with 3,900+ listings
North Indian and Chinese are the dominant cuisines
Restaurants accepting online orders have a slightly higher average rating
Average cost for two people is ₹603
